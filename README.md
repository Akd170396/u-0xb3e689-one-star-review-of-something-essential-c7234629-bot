A deadpan one-star review of the sun, written by a small deterministic Python program. The program writes one single-line review (under 160 characters) to `/output/entry.txt`: the sun rises every morning without fail, weekends included, never apologises, and offers no snooze button, no days off, no refund.

## Run it

```sh
python3 main.py
```
